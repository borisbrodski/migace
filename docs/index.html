Schema migrations you can prove.

MigAce migrates a database with real data and then proves the result is identical to the schema your application expects, down to the last constraint. No drift, no surprises in production.

The proof loop

Every build runs the same loop. If a migration doesn't produce exactly the expected schema on a database that already contains data, the build fails, long before production.

01 · TARGETGenerate schema A from your Hibernate model.
02 · RESTORELoad an older production-like dump with data into schema B.
03 · MIGRATEApply all pending snippets to B, part by part, fully logged.
04 · COMPAREDiff A and B: tables, columns, constraints, indexes, routines.
05 · SEALStore the schema digest. The app refuses to start on a mismatch.

Built for real enterprise databases

Born in a long-running Java EE project and rebuilt from scratch for PostgreSQL.

🎯

Zero-drift guarantee

Production schema matches the Hibernate-generated DDL exactly, verified on every build.

🔁

Re-runnable snippets

YAML snippets made of small parts. Each part is logged and skipped once applied, so a failed run simply resumes.

📦

Migrations on real data

Adding NOT NULL or unique constraints is tested against data, not just an empty schema.

🧮

Data migrations

First-class data and repair snippets, separate from schema changes and fully traceable.

🚦

Breaking-change detection

Define the oldest app version you still support. MigAce classifies every change as compatible or breaking against its schema, so rolling updates stay safe.

🔐

Schema digest at startup

The app checks a hash of the live schema and refuses to start against an unexpected database.

🧪

Test data generation

Generate realistic data for every new table and column so each snippet is exercised.

⚙️

Gradle-native, no containers needed

A Kotlin Gradle plugin that works against any PostgreSQL you point it at, even on locked-down build machines. One task, migaceVerify; ship by running migrations directly or as a plain SQL script for your DBAs.

🌿

Branch-friendly

Snippets from parallel branches merge automatically; conflicts surface as a failing proof in CI, not in production.

Get started (preview)

The plugin is not published yet. This is what using it will look like.

// build.gradle.kts
plugins {
    id("org.openbrod.migace") version "0.1.0"
}

migace {
    database = jdbc("jdbc:postgresql://localhost/migace_ci")
    snapshot = file("db/baseline.dump")
    snippets = file("db/migrations")
}
