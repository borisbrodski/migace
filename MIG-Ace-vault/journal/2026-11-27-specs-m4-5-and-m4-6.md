## Decided since 22 November

| Topic | Decision | Where |
|---|---|---|
| Limits | A short single wait for a lock, many attempts, about fifteen minutes in sum, no time limit for a statement. The statement of a blocking session is not stored. | [Answers](../decisions/answers-after-m4-3.md) |
| Types | The forms of standard SQL with several words, and the short names as aliases. | M4.4-AC-42 and 43 |
| Conditions | A condition belongs to one part. No `when` on a snippet. `ran` names a part. `retired` on a single part. | M4.4-AC-39 to 41 |
| Renaming | `former-names` on a part and on a snippet. | M4.5 |
| Views, functions, procedures, triggers | Replaced after all snippets, only where they changed. The ledger remembers a checksum for each. A parameter replaces all. | [Replaceable objects](../architecture/replaceable-objects.md), M4.6 |
| Snippets and these objects | A snippet does not use a view, function or procedure of the project. An error at build time. | M4.6-AC-09 to 13 |
| A new database | Created by the script from `schema/`, with the ledger and every snippet as `included`. | M4.6-AC-17 to 23 |
| Adopt | Deferred. A database with objects and without a ledger stops the run. | question 66 |
| `schema/` | One flat folder for one database. One folder per database comes with the second database. | [Replaceable objects](../architecture/replaceable-objects.md) |
